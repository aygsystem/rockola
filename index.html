Buscar temas

Para buscar desde la rockola hace falta una clave gratuita de YouTube (se hace una sola vez):
  1. Entrá a YouTube Data API en Google Cloud con tu cuenta de Google, creá un proyecto si te lo pide y tocá Habilitar.
  2. Andá a Credenciales → Crear credenciales → Clave de API y copiala.
  3. Pegala acá abajo. Queda guardada solo en este navegador.

Selecciones

Para que cada tema quede grabado en tu repo de GitHub (y aparezca en cualquier compu o celular), conectá un token una sola vez:
  1. Entrá a crear token en GitHub con la cuenta dueña del repo.
  2. Ponele un nombre (ej. rockola) y en Expiration elegí la duración que quieras.
  3. En Repository access elegí Only select repositories y marcá rockola.
  4. En Permissions → Repository permissions → Contents elegí Read and write.
  5. Tocá Generate token, copialo y pegalo acá. Queda solo en este navegador.

Para buscar por tema o artista usá el buscador de arriba. Acá podés pegar un link directo si ya lo tenés.
